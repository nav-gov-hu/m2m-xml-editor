XML EDITOR MINTA

XML feldolgozás, felderítés és űrlapnézet

XSD, UIModel és XML alapú feldolgozás egy korszerű, vállalati felületen. A rendszer célja a sémák felderítése, a validáció támogatása és az XML tartalom űrlap alapú áttekintése és szerkesztése.

Rendszeráttekintés

Projekt célja

Java 17 és Maven alapú, többmodulos eszköz XSD vezérelt XML feldolgozáshoz, CLI integrációhoz és webes hosztoláshoz.

A webes felület támogatja a sémafeloldást, az XML validációt, a UIModel-alapú űrlapnézetet és az XML-fa alapú kétirányú navigációt.

Modulok

  • nav-xsd-parser-tool-core — közös domain modellek
  • nav-xsd-parser-tool-schema-registry — schema bundle feloldás
  • nav-xsd-parser-tool-xsd — XSD parser szerződés
  • nav-xsd-parser-tool-uimodel — UI model parser szerződés
  • nav-xsd-parser-tool-page-schema — .schema parser szerződés
  • nav-xsd-parser-tool-processing — feldolgozási és XML probe logika
  • nav-xsd-parser-tool-cli — futtatható CLI JAR
  • nav-xsd-parser-tool-web — Spring Boot web host

Build

mvn clean package

A statikus assetek verziózása build közben automatikusan történik.

CLI példák

java -jar nav-xsd-parser-tool-cli/target/nav-xsd-parser-tool-cli.jar inspect --xml C:\input\sample.xml --schema-dir C:\schemas
java -jar nav-xsd-parser-tool-cli/target/nav-xsd-parser-tool-cli.jar validate --xml C:\input\sample.xml --schema-dir C:\schemas
java -jar nav-xsd-parser-tool-cli/target/nav-xsd-parser-tool-cli.jar generate --document-type T34 --schema-dir C:\schemas --out C:\output\empty.xml

Web indítás

java -jar nav-xsd-parser-tool-web/target/nav-xsd-parser-tool-web.jar

Az alkalmazás indítása után a webes felület a böngészőből használható.

Fő lépések

  1. Nyisd meg a Felderítés / Validálás nézetet.
  2. Add meg a séma könyvtárakat és az XML forrást.
  3. Futtasd az elemzést vagy a betöltést.
  4. Érvényes XML esetén válts az Űrlapmegtekintő nézetre.

Megjegyzések

  • A FileSystemSchemaRegistryService jelenleg xsi:schemaLocation vagy fájlnév alapján oldja fel az XSD-ket.
  • A sématár induláskor előindexeli a konfigurált sablon és általános XSD könyvtárakat, így az inspect és validate műveletek gyorsabban futnak.
  • A következő fő feldolgozási lépés a valós XSD parsing és definition merging továbbfejlesztése a feldolgozási modulokban.

Futtatás

Az XML feltölthető, vagy megadható szerver oldali elérési úttal.

Ha üresen hagyod, a rendszer a konfigurációban megadott schema-dir értéket használja.

Ide kerülhetnek a közös XSD-k, például a common.xsd vagy az altalanos_enum.xsd.
