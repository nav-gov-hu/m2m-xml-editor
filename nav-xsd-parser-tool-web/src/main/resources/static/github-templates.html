GitHub token nincs beállítva

A helyi űrlapsablon-katalógus használható, de GitHub-ellenőrzés és release-letöltés csak hozzáférési token megadása után indítható.

A token titkosítva kerül tárolásra. Az értéket mentés után nem jelenítjük meg újra.

A részletes GitHub beállítások továbbra is elérhetők a Rendszer → Konfiguráció → GitHub oldalon.
