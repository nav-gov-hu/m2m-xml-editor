M2M XML EDITOR beállítása

Az alapértelmezett H2 adatbázis automatikusan létrejön. A kötelező alapbeállítások után opcionálisan megadhatók a GitHub- és NAV M2M-hozzáférési adatok is.

A továbblépéshez sikeres kapcsolati teszt szükséges.

H2 esetén a felhasználónév alapértelmezetten sa. Külső adatbázisnál a rendszer a szükséges JDBC driver- és Flyway-beállításokat automatikusan generálja.

A rendszer létrehozza a config, database, logs, certificates, backup és data alkönyvtárakat.

A kezdő admin jelszava legalább 8 karakteres legyen, és tartalmazzon kisbetűt, nagybetűt, számot és speciális karaktert.

GitHub hozzáférés

A token a GitHub sablonkatalógus és a release-ek eléréséhez használható. Üresen hagyható.

NAV M2M felhasználói regisztráció

A NAV-tól kapott teljes API-kulcsot egy mezőben adja meg. A rendszer a kötőjelek alapján automatikusan szétbontja és a részeket a megfelelő helyen menti.

NAV M2M kliensregisztráció

A Client ID és a Client Secret csak együtt adható meg. Mindkét mező üresen hagyható.

A mentés után a telepített asztali alkalmazás automatikusan újraindul.
