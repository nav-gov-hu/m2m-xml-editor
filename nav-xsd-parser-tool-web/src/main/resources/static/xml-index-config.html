XML index konfiguráció

Melléklap index konfiguráció szükséges.
A melléklapok kezeléséhez válassza ki azokat a mezőket, amelyek alapján keresni szeretne (Kereshető), illetve amelyek megjelenjenek a találati listában (Lista). Legalább egy Kereshető és egy Lista mezőt állítson be, majd mentse a konfigurációt.

A melléklaptáblázat oszlopai kizárólag a Lista jelölésű mezőkből, a keresés pedig kizárólag a Kereshető jelölésű mezőkből épül fel.
